# NotesへのMarkdown取り込み

Notesの一覧へ `.md` / `.markdown` / `.mdown` / `.mkd` ファイルを落とすと、1ファイルにつき新しいNoteを作る。既存Noteは上書きしない。保存先は表示中のTheme、Themeがなければ個人業務とする。

題名はfrontmatterの `title`、本文先頭のH1、ファイル名の順で選ぶ。frontmatterと題名に使ったH1は本文から外し、frontmatterの題名と違うH1は本文へ残す。H1として扱うのは行頭の0〜3スペースと `#` で始まる見出しだけで、4スペース以上の字下げやタブによるコード行を削除しない。相対リンクと画像の参照先は書き換えない。

一度に20ファイル、1ファイル2MiBまで。Markdown以外は保存しない。全ファイルの読み取り完了後、既存の保存Commandで一度のtransactionとして適用する。読み取り失敗時も保存失敗時も新規Noteを作らず、読み取り失敗にはファイルのアクセス確認と再ドロップを案内する。成功したら先頭のNoteを選択する。
