# 公開記録評価のlive結果

このファイルを評価ごとに複製して記録する。
初期値はすべて`not_run`であり、実際に観測した層だけを変更する。
手順は[公開記録の振り返り評価](publication-context-evaluation.md)を参照する。

## 評価対象

| 項目                       | 記録                                                          |
| -------------------------- | ------------------------------------------------------------- |
| 評価ID                     | 未記入                                                        |
| Tasken release / commit    | 未記入                                                        |
| ローカル実行日時とtimezone | 未記入                                                        |
| 出力先とverification.json  | 未記入                                                        |
| fixture生成日時            | 初期2026-09-08T01:00:00.000Z / 訂正後2026-09-08T02:00:00.000Z |
| アカウント種別             | 未記入（個人 / 仕事。秘密情報は記載しない）                   |
| OneDrive評価専用保存先     | 未記入                                                        |
| コピー対象                 | `current/Tasken Context/`のみ                                 |
| 既存証跡との関係           | 未記入（個人OneDriveの過去証跡は今回の成功と区別する）        |

## 4層の判定

| 層       | 判定    | 観測日時 | 証拠と確認範囲                                | 未確認事項または失敗理由 |
| -------- | ------- | -------- | --------------------------------------------- | ------------------------ |
| local    | not_run | 未記入   | verification.jsonへの参照                     | 未記入                   |
| cloud    | not_run | 未記入   | OneDrive Webの公開README、日別、Sourcesの確認 | 未記入                   |
| search   | not_run | 未記入   | M365 Copilotで見つかった対象ファイルとリンク  | 未記入                   |
| grounded | not_run | 未記入   | 下表の4問と引用先の照合                       | 未記入                   |

localだけが成功した場合、cloud、search、groundedは`not_run`のままにする。
仕事アカウントで未実施なら「release後にユーザーが確認」と記録する。

## 訂正後の公開内容の確認

| 確認項目                                                       | 判定と証拠 |
| -------------------------------------------------------------- | ---------- |
| 訂正値CORRECTED_548と全文末尾FULL_TEXT_END_548                 | not_run    |
| 私的本文NEVER_EXPORT_548と取消し本文WITHDRAW_548が公開物にない | not_run    |
| 古い値SUPERSEDED_548が公開物にない                             | not_run    |
| 遅延入力LATE_548は9月4日実施として読める                       | not_run    |
| READMEの観測時刻、未公開範囲、未送信不明の表示                 | not_run    |

旧ファイルや旧回答がクラウド側に残る場合は、対象と確認日時を記録する。
ローカル撤去からクラウド上の全複製や索引の削除を推定しない。

## 残作業

未実施の確認、再試行する層、担当者を記入する。
評価用ファイルの保管先や撤去状況も記録し、本番Workspaceへのimportは行わない。
