# AI作成とTaskボードの統合

明示的なcreate-only経路で作成した本人用Task/Noteを、既存一覧・ボード・課題会話で扱う。
AI作成由来はアイコン、未確認は小さな点で示し、タップ／クリック／キーボードで作成元と状態を読む。
「見た」は既読metadataだけを保存し、Task完了やAI報告の採用とは分ける。

課題の正本は既存Task/Proposal/WorkReceipt/Feed。依頼・質問・返答・成果報告・修正依頼と人の会話を同じ課題から扱う。
AI作成Taskは本人実行・未委任で始まり、利用者が既存の依頼操作でAIへ渡す。

## カンバンの操作

ToDoのボードは同じTaskを未着手・進行中・確認待ち・待ち・完了・中止で表示する。
列間のドラッグで状態、カードへのドロップでその直前への順序を変更する。
状態選択と上下ボタンでも同じ操作を行え、列内の上ほど次に取り組む順序とする。
`board_order`は列内の手動順序としてTaskへ保存する。未設定のTaskは作成日時とIDの安定順で末尾へ表示する。
複製と繰り返しの次回Taskは新規Taskとして順序を未設定にし、元Taskや別列の優先順位を引き継がない。
絞り込み中も順序計算は全Taskを対象とし、非表示Taskの状態・相対順を維持する。
状態と順序は一括保存し、失敗時はカードを元の位置に残してエラーを表示する。
完了への移動は既存の繰り返しTask生成とAI報告採用後の完了制約を守る。
列内の順序変更だけでは完了の取り消しや繰り返しTask生成を行わない。

カードにはTheme、担当・次の手番、予定終了日、チェック項目の進捗を表示する。
未終端の列からタイトルを入力してTaskを追加でき、保存失敗時は入力を保持する。
完了・中止は通常折りたたみ、列見出しから展開する。狭い画面では列の横スクロールを保つ。長い列は列内で縦スクロールし、横スクロールの入口が画面下へ押し出されないようにする。
一覧の並び替え・グループ設定はボードの手動順序に適用しない。

カードのAI依頼はClaude Code / Codexへ引き渡す入口とする。
依頼後の会話は外部AIで続け、Taskenは既存MCPで受けた報告を記録・採用する。
CLI起動だけでは着手済みとせず、AIからの開始報告を待つ。

`scripts/task-handoff-audit.mjs --task-board --integrated` は実Core作成、一覧/ボードの同じID、既読保存、競合時の返答保持、報告採用後のTask継続、2つの隔離DB間の共有folder同期、Electron再起動を確認する。
ソースからの再生成と隔離previewは [task-board-ci-integration.md](task-board-ci-integration.md) を参照。
