# Sketch Canvas mode comparison

## 比較する二つの作業面

| 観点 | Page | Infinite |
|---|---|---|
| 主用途 | 手書きノート、Note埋め込み、順序のある説明 | 構想、関係図、広がりながら考える図解 |
| 面 | 1200 × 850の固定比率 | 2400 × 1600から開始し、右端・下端の描画に応じて800px単位で拡張 |
| 移動 | 通常のscrollとzoom | 移動ツールまたは中ボタンドラッグ、scroll、zoom |
| 複数面 | ページを追加 | 一つの連続面 |
| Export | 現在のページ | 描画範囲（既定）またはキャンバス全体 |
| 既存データ | modeなしの既存SketchはPageとして読む | 新規作成時に明示選択 |

## 同一サンプル

両modeで次の「実験判断フロー」を作り、道具や内容を変えずに比較する。

1. 左上にテキストで「仮説」。
2. 中央に矩形を3つ並べ、「条件A」「観察」「判断」と書く。
3. 矩形を矢印で接続する。
4. ペンで矩形の周囲に注記を2つ書く。
5. 蛍光ペンで重要箇所を1つ強調する。
6. 画像を1つ貼り、図形と整列させる。

Pageでは内容が収まらなければ2ページ目へ続ける。Infiniteでは右方向へ続け、端付近へ描いて自動拡張を確認する。

## 評価観点

各項目を1（つらい）〜5（自然）で記録する。

- 書き始めるまでの迷い
- 全体像の把握
- 追記する場所の見つけやすさ
- ペン／図形／テキストの操作差
- Noteへ埋め込んだときの読みやすさ
- PNG / SVGへ出す範囲の分かりやすさ
- 10分後に戻ったときの現在地の分かりやすさ

## 現時点の境界

modeはSketch document全体の契約で、作成後に切り替えない。既存Sketchの読み取りを壊さず比較結果を取るためであり、本採用判断後に既定modeと変換要否を決める。
