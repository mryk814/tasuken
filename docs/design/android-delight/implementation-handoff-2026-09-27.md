# Android Tasken 初期実装の引き継ぎ

2026-09-27。初回実装を依頼した範囲と、その後の確認境界をまとめた記録です。初期範囲は現行コードに実装済みです。現在の実装状況と後続案は[改善計画](plan-2026-09-27.md)を参照してください。

## 初期実装の範囲

- Todayでは今日のTaskと追加・音声入力を主役にし、通常時の同期情報を簡潔にする。
- 未同期・競合・保存失敗は状態と復旧操作を保つ。
- Task完了には短い視覚的な反応を加え、完了後も一覧位置とfocusを保つ。
- 端末への保存成功を確認してから保存印と触覚を返し、同期・再描画で反応を繰り返さない。
- Today / ToDo / AIの3タブ、既存のTask順、右手の操作範囲、正式データの保存経路を維持する。

## 対象外とした範囲

Recallの手帳表現とAI画面の刷新は後続段階です。ポイント、育成、推薦、追加の通知、タイマー、新しいDB schemaも初期範囲に含めません。
画像内の文字、架空の研究データ、装飾は要件ではありません。細部の補正は[生成記録](image-prompt-2026-09-27.md)を参照してください。
