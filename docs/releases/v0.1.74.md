# Tasken v0.1.74

Taskボード、課題ごとのAI会話、AI由来の表示、限定したTask開始に、日次Activity、hooks不要のログ同期、Androidの4タブとFeedを統合する。
Windows Desktop・Core・MCP・Androidを同じリリースcommitから生成する。AndroidはversionName `0.1.74`、versionCode `66`、Room schema `29`。

## 新機能

- 既存Taskを一覧とボードで確認し、課題の依頼・質問・返答・成果報告を追える。
- 明示的に有効化した本人用のAI作成経路でTaskとNoteを追加できる。AI由来と未確認の印をDesktop／Androidで確認し、既読にできる。
- 開始専用権限を独立して有効化すると、人がAI ReadyにしたTaskを外部AIが開始できる。成果報告の採用とTaskの正式完了は引き続き人が行う。
- Codex、Claude、GitHub Copilot、OpenCode、DeepSeek Harnessの選択した作業ログをプレビューし、Proposalとして採用できる。日／週のタイムラインとAndroidの詳細へつなぐ。
- Activityで人の操作・フォーカスとAIセッションを同じJSTの日に確認し、依頼・成果・関連タスクの詳細を開ける。終了未確認は最終観測まで表示し、経過時間と実働時間を区別する。費用・実働時間の未収録をゼロとして扱わない。
- Codex / Claude Codeのログ保存先から新規・変更JSONLを収集できる。場所の件数・更新日時、保存内容、現在の共有同期先を確認して登録する。読み取り専用で短い秘匿済み抜粋を提案にし、生ログ全文やtool / reasoningは保存しない。5分ごとの同期はTasken起動中だけで初期状態は無効。WSL / portable / 別プロファイルは場所を指定する。
- Androidの下部を今日 / Task / Feed / 記録に整理し、検索・同期・設定を共通の上部へ置いた。長押し操作、Task詳細の戻る導線、日付ごとの記録を揃えた。
- AndroidのFeedでPCの投稿を読める。返信（自分のメモ）、おもしろい、ブックマークは先に端末へ保存し、同じcommandIdで再送する。投稿の密度を調整し、本文・添付・操作を一つの流れで表示する。

## 更新時の注意

新しい作業ログの形式を採用する前に、同じworkspaceのDesktop／Core／MCPをこの版へ揃える。
旧Coreは`unknown`／`interrupted`状態とOpenCode／DeepSeek HarnessのAgentSessionを受け付けない。
NASを使用する場合は、そのCore／MCPの更新も済むまで新形式ログの採用を待つ。
Feedのread modelに反応・返信が増えるため、旧APKは新DesktopからFeedを更新できず、保存済み投稿を表示し続ける。PCとAndroidを同じ統合版で準備し、片側だけを先に常用環境へ入れない。書き込み口のないheadless接続先ではFeed操作を送れず、Androidは未送信入力を保持する。更新でNASの権限を拡張しない。

DesktopのSQLite migrationはv0.1.73から変更していない。
AndroidはRoom 26→27→28→29でAI由来cache・Feed cache・Feed未送信操作を追加し、既存Taskと未送信操作を保持する。
Androidはアプリを削除せず、既存署名と互換性のあるAPKで更新する。
新ログ保存後にコードだけを旧版へ戻したり、Room 29のデータを旧APKで開いたりしない。
復旧が必要ならwriterを止め、更新前の端末保存状態・共有sync状態・componentを一組で戻す。

## 有効化と配布範囲

AI作成は明示的なcreate-only設定、AI開始は独立した`TASKEN_CORE_AI_TASK_START=1`が必要で、既定では無効。
ログ取込はfile選択または利用者が登録した保存先から行い、Proposalを確認して採用する。ホーム全体の探索やhookの導入は行わない。定期同期は個別のopt-inで、登録場所はPCのuserDataに保存する。
このリリースはWindows installer／portable、恒久署名Android APKとSHA-256を公開する。
通常Desktop、署名互換のAndroid、Tasken NASはバックアップとwriter停止を確認した一組の更新として扱う。credentialsや既存の書き込み権限は変えない。

更新・復旧の手順は[Release](../release.md)、component契約は[manifest](../tasken-integration-manifest.json)を参照。
