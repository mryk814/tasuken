# Tasken v0.1.45

## タスクからAIへ依頼

- Windowsのタスク編集画面から、Claude CodeまたはGitHub Copilotと作業先フォルダを選んで起動できます。Task IDとTaskenのMCP接続を渡し、そのタスクに紐づけて作業を始められます。
- 委任待ちにして外部AIから取得する経路、依頼文をコピーする経路も引き続き利用できます。各CLIのログイン・権限確認は省略しません。
- Today／ToDoのタスク名から編集画面へ直接入り、AIへの依頼も同じ場所で準備できます。

## AI作業の確認と日報

- AI作業を「意図・結果・残り」で読みやすく整理し、要確認の作業を優先表示します。内容の少ない記録は削除せず、まとめて畳みます。
- Debriefは一日の時系列を先頭に表示し、AI作業はカードとホバー表示で確認できます。
- MCPの`daily-report`プロンプトから、当日のアクティビティと公開可能な作業記録をもとに日報を作成できます。固定の振り返りフォームに代えて、その日に応じた問いと本人が書き込む欄を含むReport Noteを編集する流れにしました。

## MCP登録と保存の安定性

- ノート・レポート・プロンプトの種別、実際に使える紐付け操作、Tasken向けMarkdownの書き方をMCPで案内します。提案の採用前に種別と本文を確認できます。
- ノートのTheme変更と添付ファイルの所属を同じ保存経路で扱い、保存中の本文やMarkdown未同期の再試行を保護しました。
- Theme未指定のノート・日報の保存先を「個人業務」に揃えました。既存データの一括書き換えは行いません。
- WindowsでCore接続情報を更新する際の一時的なファイル使用中エラーからの回復を改善しました。

## Android

- タスク追加時にタイトル入力へフォーカスし、状態変更やTheme選択の導線・表示をデスクトップ版に合わせました。
- ランチャーアイコンをTaskenのアイコンに変更しました。

## 検証範囲

実際のClaude Code／GitHub Copilotによる作業の完遂・結果報告までは確認していません。CLIの起動とAIの作業完了は別の状態です。
