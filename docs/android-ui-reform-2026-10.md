# Android UI改革（2026-10）

Androidの導線を「何をしたいときに、どこを押すか」から作り直した。
データ、同期、保存の契約とRoom schemaは変えていない。変えたのは見せ方と入口だけである。
改革案と現状の課題は、利用者と合意した提案ページ（`output/android-ui-reform-2026-10-04/proposal.html`）を元にしている。

## 骨格

| 項目         | 以前                                                    | 現在                                                                  |
| ------------ | ------------------------------------------------------- | --------------------------------------------------------------------- |
| 下部タブ     | Today / ToDo / AI                                       | 今日 / Task / Feed / 記録                                             |
| 上部右側     | タブごとに異なるアイコンと状態チップ（最大7個）         | 全タブ共通で 検索・同期・設定 の3つ                                   |
| 追加（＋）   | Today・ToDoのみ                                         | 全タブ。Foldの展開幅ではナビゲーションレールの先頭                    |
| 同期の状態   | 上部の「PCへ未反映 n」「要確認 n」、Todayの同期済み表示 | 雲アイコン（正常は緑の点、要対応は件数）→ 同期シート                  |
| 設定         | AIタブ上部のリンク・チェックボックス、上部の文字ボタン  | 歯車 → 設定シート（通知・Feedの質問通知・PCなし整理・接続のやり直し） |
| 今日の記録   | Todayの上部アイコンからのシート                         | 記録タブ（日ごとのタイムライン、先頭に「一言残す」）                  |
| 端末内検索   | ToDo一覧の中の文字ボタン                                | 上部の検索アイコン                                                    |
| Foldの展開幅 | 下部タブ＋2ペイン                                       | 左のナビゲーションレール（＋付き）＋2ペイン                           |

タブ名はDesktopの呼び方（Task・Feed）に揃えた。

## Feed

AIを特別扱いせず、DesktopのFeedと同じ「読む面」として扱う。
対応待ち（あなたの返事を待つ投稿）と最近の動きを1本の流れに並べ、「すべて / 対応待ち」で切り替える。
投稿者は頭文字の丸（出所ごとに色を変える）で示し、投稿は枠で囲まず細い線で区切る。
AI由来はこれまでの印（AiOriginMark）で示し、それ以上の強調はしない。
投稿を長押しすると操作メニューを開ける。

DesktopのFeed投稿は `GET /v1/feed`（`mobile:read`）でAndroidへ届く。範囲はDesktopのFeed画面と同じ（削除されていない `feed_posts` Proposalと、自分の `feed_post`）で、新しい順に最大50件を返す。
投稿者の判別規則は `src/shared/feedAuthors.mjs` をDesktopの画面とgatewayの射影が共有する。
記事の草稿は題名だけ、外部リンクはURLと表題だけを流し、本文・根拠・画像・返信・反応は流さない。作業報告はこれまでどおりTaskの経路で届くため含めない。
Androidは受け取った並びのまま `feed_cache` に置き換えて保存する（Room 27→28。Desktopで消した投稿は残らない）。取れなかったときと、この窓口を持たない古いDesktopのときは、保存済みの投稿をそのまま見せる。
自分の投稿は「新着」にも未読の印にも数えない。リンクを開けるのはhttp(s)だけである。
契約は `contracts/mobile/v1/feed-response.golden.json` をDesktop（`tests/mobile-feed-golden.test.mjs`）とAndroid（`MobileFeedGoldenTest`）が共有する。

## 操作

- 今日・Taskの行：タップで開く、右へ払って完了、左へ払って明日へ（Taskタブでは今日へ）、長押しでメニュー（完了・明日へ・今日の予定から外す・やったことを残す・開く）。
- 払う操作は初回だけ一行のヒントで知らせる。閉じると以後は出さない（端末内の `tasken_ui_hints` に記録）。
- 追加ボタン：「＋（書く）」と「マイク（話す）」を1つの面に並べ、押す時点で選ぶ（スマホは横並び、Foldのレールは縦並び）。シート上部で Task / メモ / やったこと を切り替える。2026-09-11に外したTask / Captureの切り替えを、メモの明示的な選択として戻した。500文字を超える入力は、従来どおり自動でメモとして保存する。
- Task詳細：左上の矢印で戻る（右へ払っても戻る）。状態・日付・Theme・予定の札、記録する・資料・Theme・AIに任せる の4ボタン、下部に固定した「今日の予定」と「完了する」を置く。
